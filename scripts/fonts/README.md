# iaito95

iaito95 is an outline repair fork of W95FA 1.002 by Alina Sava / FontsArena.com.
The original font and its unchanged SIL Open Font License are in `w95fa/`.
Source: https://fontsarena.com/w95fa-by-alina-sava/

The font and its generator are distributed under the SIL Open Font License 1.1.
Original design credit remains with Alina Sava / FontsArena; iaito95 identifies
the modified version and does not imply upstream endorsement.

Files included in the repository:

| File | Purpose |
| --- | --- |
| `scripts/fonts/w95fa/W95FA.otf` | Unmodified W95FA 1.002 source font |
| `scripts/fonts/w95fa/OFL.txt` | Unmodified upstream license, including its original line endings |
| `scripts/fonts/build_iaito95.py` | Reproducible outline, metric and hinting repair generator |
| `src/fonts/iaito95.ttf` | Generated TrueType font, family and PostScript name `iaito95` / `iaito95-Regular` |
| `src/fonts/iaito95-LICENSE.txt` | Attribution notice followed by the original license bytes |
| `tests/fonts/test_iaito95.py` | Compiled hinting and rasterization checks |
| `scripts/fonts/UPSTREAM.md` | Findings and a draft note for the original author |

The generator snaps the original outlines onto a 50-unit grid, merges adjoining
filled regions, removes interior edges and microscopic gaps, and gives glyphs
consistent half-cell side bearings. It preserves all 160 original glyphs and 167
Unicode mappings, and adds standard ellipsis and multiplication/close-mark
characters so tab labels and close buttons do not fall back to another font.
Vertical metrics include the full accented capitals and descenders.
The result is a TrueType vector font with no embedded bitmap strikes.

The family is renamed **iaito95**, displayed as **iaito95** in Appearance.
Saved `W95FA` and `Iaito W95FA` selections migrate to this family automatically.
Classic uses 10 logical pixels with antialiasing disabled. Main strokes are one
logical pixel wide (two physical pixels on Retina). The finer accent grid also
lands on whole Retina pixels.

The font includes TrueType instructions that fit individual strokes to device
pixels at other sizes. Snapping the vector outlines to a design-unit grid alone
does not achieve this: independent edge rounding gave `o` a 3-pixel left stem and
a 4-pixel right stem at 16px on Retina, and distorted the steps in `A`.
The fitter keeps stem widths equal, preserves symmetry and joins, and adjusts
counters and step lengths within the existing advances and vertical metrics.
Whole-design scaling would instead introduce overlapping letters and clipping.
Qt requests full hinting for this font, including the Classic interface font.
At startup iaito also raises Qt's cached-glyph size limit to 512 device pixels
(unless explicitly overridden). Qt's default 64px cutoff switches large text to
paths, bypassing the font's instructions and introducing gray edge pixels.
See Qt's [`shouldDrawCachedGlyphs` implementation](https://github.com/qt/qtbase/blob/v6.11.2/src/gui/painting/qpaintengineex.cpp#L1015).

The square pixel steps are part of W95FA's design. The result remains a vector
font, with no embedded bitmaps. Fitting starts at 10 physical pixels per em;
smaller sizes lack enough pixels to retain every feature. Hint patterns repeat
every 20 physical pixels because all original coordinates are multiples of
1/20 em. The generator encodes the corrections using standard TrueType bytecode.

From the repository root, rebuild using Python 3 and `fonttools==4.42.0`:

```sh
python3 -m venv /tmp/iaito95-env
/tmp/iaito95-env/bin/pip install fonttools==4.42.0
/tmp/iaito95-env/bin/python scripts/fonts/build_iaito95.py
/tmp/iaito95-env/bin/python scripts/fonts/build_iaito95.py --check
```

With FontTools already installed:

```sh
python3 scripts/fonts/build_iaito95.py
python3 scripts/fonts/build_iaito95.py --check
```

Normal iaito builds use the committed font and do not require FontTools.
The generator verifies the upstream SHA-256, character coverage, grid coordinates,
spacing, vertical bounds and every filled/empty grid cell in the compiled font.
It also checks that the font and bundled license can be regenerated byte for byte.
The Qt appearance tests render `o` and `A` at sizes 10–32 in pixels and points,
with 1x, 1.25x, 1.5x and 2x device ratios and fractional text origins. They check
equal stems, symmetry, sharp pixels and layout bounds, rather than checking only
the absence of gray.

With `freetype-py==2.5.1` installed, the compiled bytecode can also be checked with:

```sh
python3 tests/fonts/test_iaito95.py
```

This executes every glyph at 10–216 physical pixels with FreeType's strict
interpreter, checking fitted positions, ink and layout bounds.
The generator verifies SHA-256 hashes of both upstream files before rebuilding;
the source font and source license are never rewritten.
